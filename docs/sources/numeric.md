## Conflicts / caveats

1. **Brief says "Pakistani brand 'Numeric Power' / Numeric UPS and Solar"; evidence says the UPS "Numeric" brand is Indian.** The only working "Numeric" UPS site (numericups.com) self-describes as "40 Years of Powering India" and "Engineered for India's Grid", with a Chennai head office and 218 Indian service centres. "Numeric Power Systems Ltd" is a defunct Indian listed company whose UPS brand and IP were sold to Legrand in 2012 and which was later renamed SWELECT Energy Systems.
2. **The domain given in the brief, `numericpower.com`, is not a company site at all** — it is a parked domain offered for sale by HugeDomains, which is a strong signal the brief's assumption came from an inference rather than a source.
3. **Name collision inside Pakistan:** `numeric.com.pk` exists but is a Karachi IT-services firm, not a power brand. Any naive "Numeric + Pakistan" match will land on it and produce wrong data.
4. **Two unrelated historical "Numeric Power" entities collide in search results** — the Indian UPS maker (now Legrand) and the Indian solar/PCU maker (now SWELECT). Neither is Pakistani; both must stay quarantined separately.
5. **No source-level conflict was found on codes**, because no code table for a Pakistani Numeric was located at all. The only code conflicts would be between the Indian Numeric manuals themselves (e.g. the "Battery reverse" / "Input Neutral Line Missing" wording differs between the HPi 33 EVO and Premius Edge tables, and code 22 is labelled differently) — but these are out of scope for this PK brand and were not resolved.
