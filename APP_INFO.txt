 FULL DESCRIPTION (max 4,000 characters)
--------------------------------------------------------------------------------

AC Ustad is an offline error-code reference for air-conditioner and
solar-inverter technicians. When a unit shows a fault code like E6, F4,
Error 200, ID013, or a blinking LED pattern, AC Ustad tells you what it means,
what causes it, and how to fix it - in plain English or Roman Urdu, with no
internet connection needed.

BUILT FOR THE FIELD
The complete knowledge base is bundled in the app: 62 brands, 320 model lines
and 4,418 error codes. Open it in airplane mode and every answer is still
there. No account, no sign-up, no waiting for a server.

SCOPED TO THE EXACT UNIT
The same code can mean completely different things on different machines.
AC Ustad always identifies a code by brand, model line and code - never by the
code string alone - so you read the answer for the unit in front of you, not an
average across brands.

EVERY CODE INCLUDES
- A severity label: DANGER, STOP, CHECK, CLEARS, INFO or INDICATOR
- A plain-language meaning
- Numbered, step-by-step fix instructions
- Possible causes
- A source reference from the service manual

ENGLISH AND ROMAN URDU
Switch the whole app in one tap. Meanings, fix steps, causes and severity words
all change together, and your choice is remembered offline.

SEARCH AND SAVE
Search brands, model lines and codes from any screen, with technician keywords
such as "air leakage" or "water pump". Star the codes you use most and find
them in the Saved tab; swipe to remove with undo.

PRIVATE BY DESIGN
No account. No analytics. No crash reporting. No tracking beyond the ads that
keep the app free. Your saved codes and settings stay on your phone. The
knowledge base never needs the network: in airplane mode the ad slots are
simply empty and every code still works.

ADS
AC Ustad is free and supported by Google AdMob. Ad networks may see your device
and IP address when an ad loads. The app asks for consent where required and
requests no runtime permissions.

COVERAGE
Air conditioners and solar inverters from 62 brands used across Pakistan and
the region, including split ACs, inverter ACs, VRF systems and hybrid solar
inverters. Every code is sourced from manufacturer manuals and service
documentation.

WHO IT IS FOR
AC technicians, solar installers, service engineers, shopkeepers and anyone who
needs a straight answer from a fault code without carrying a folder of manuals.

Works offline. Free. No account. English + Roman Urdu.
