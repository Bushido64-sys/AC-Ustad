What AC Ustad Does

AC Ustad is an offline reference app built for air-conditioner and solar-inverter technicians in Pakistan. When a unit shows a fault code like E6, F4, Error 200, ID013, or a blinking LED pattern, this app tells you what it means, what causes it, and how to fix it, in plain English or Roman Urdu, with no signal required.

How It Works

Browse by unit type (air conditioner or solar inverter), pick the brand, select the model line, and you get every fault code for that exact unit. Each code comes with a severity label, a clear meaning, numbered fix steps, possible causes, and a source reference. Information always comes from the specific model you have selected, never averaged across brands, because the same code can mean completely different things on different machines.

Offline First

Once installed, everything works in airplane mode. No account, no signal, no waiting. The complete knowledge base of 62 brands, 320 model lines, and 4,418 codes lives on your phone.

Built for the Field

Every code includes at least two causes and two fix steps, written in both English and Roman Urdu, so you can read in whichever language you think in. The app is ad-supported and free to use, so more technicians can access reliable, manual-based answers instead of guesswork.

Privacy

Nothing leaves your phone except Google's ad placements. There are no accounts, no analytics, no crash reporting, and no tracking beyond the ads that keep the app free. Your saved codes stay on your device.
