  Google Play App Signing:
    - Enroll in Play App Signing (the default when you create the app).
    - Google then holds the APP SIGNING key; the key above becomes your
      UPLOAD key. You keep signing future uploads with it.
    - After the first upload, Play Console -> Setup -> App integrity shows the
      App signing key certificate SHA-256. Copy it into your password manager.
    - If you lose the upload key, you can request an upload key reset in Play
      Console. The app signing key itself cannot be reset - back it up.

  Do not lose this keystore. Without it you cannot upload updates unless Play
  lets you reset the upload key.

 4. PLAY CONSOLE - CREATE THE APP
--------------------------------------------------------------------------------

  1. Sign in at https://play.google.com/console with the developer account.
  2. All apps -> Create app.
  3. Fill:
       App name ................ AC Ustad
       Default language ........ English (United States) - en-US
       App or game ............. App
       Free or paid ............ Free
  4. Tick the Developer Program Policies and US export laws declarations.
  5. Create app.
  6. Left menu -> Setup -> App signing -> enroll in Play App Signing.
  7. Left menu -> Monitor and improve -> Policy and programs -> App content.
     Complete every card using sections 7, 8 and 9 below.
  8. Left menu -> Grow -> Store presence -> Main store listing.
     Paste the copy from section 5 and upload the assets from section 6.

  Account note: a NEW personal developer account (created after 13 Nov 2023)
  must run a closed test with at least 12 testers for 14 continuous days
  before it can apply for production access. An organization account does
  not have this requirement. Check Play Console -> Publishing overview for
  the exact status of this account.

  App name (max 30 chars):
  AC Ustad: AC & Inverter Codes

  Short description (max 80 chars):
  Offline AC & solar inverter error codes and fixes in English or Roman Urdu.

  Full description (max 4000 chars):
  AC Ustad is an offline error-code reference for air-conditioner and
  solar-inverter technicians. When a unit shows a fault code such as E6, F4,
  Error 200, ID013, or a blinking LED pattern, AC Ustad tells you what it
  means, what causes it, and how to fix it - in plain English or Roman Urdu,
  with no internet connection required.

  BUILT FOR THE FIELD
  The complete knowledge base is bundled in the app: 62 brands, 320 model
  lines and 4,418 error codes. Open it in airplane mode and every answer is
  still there. No account, no sign-up, no waiting for a server.

  SCOPED TO THE EXACT UNIT
  The same code can mean completely different things on different machines.
  AC Ustad always identifies a code by (brand, model line, code), never by the
  code string alone, so you read the answer for the unit in front of you -
  not an average across brands.

  EVERY CODE INCLUDES
  - A severity label: DANGER, STOP, CHECK, CLEARS, INFO or INDICATOR
  - A plain-language meaning
  - Numbered, step-by-step fix instructions
  - Possible causes
  - A source reference from the service manual

  ENGLISH AND ROMAN URDU
  Switch the whole app in one tap. Meanings, fix steps, causes and severity
  words all change together, and your choice is remembered offline.

  SEARCH AND SAVE
  Search brands, model lines and codes from any screen, with technician
  keywords such as "air leakage" or "water pump". Star the codes you use most
  and find them in the Saved tab; swipe to remove with undo.

  PRIVATE BY DESIGN
  No account. No analytics. No crash reporting. No tracking beyond the ads
  that keep the app free. Your saved codes and settings stay on your phone.
  The knowledge base never needs the network: in airplane mode the ad slots
  are simply empty and every code still works.

  ADS
  AC Ustad is free and supported by Google AdMob. Ad networks may see your
  device and IP address when an ad loads. The app asks for consent where
  required and requests no runtime permissions.

  COVERAGE
  Air conditioners and solar inverters from 62 brands used across Pakistan
  and the region, including split ACs, inverter ACs, VRF systems and hybrid
  solar inverters. Every code is sourced from manufacturer manuals and
  service documentation.

  WHO IT IS FOR
  AC technicians, solar installers, service engineers, shopkeepers and anyone
  who needs a straight answer from a fault code without carrying a folder of
  manuals.

  Works offline. Free. No account. English + Roman Urdu.

  First Google Play release.
  - 62 brands, 320 model lines and 4,418 error codes, fully offline
  - English and Roman Urdu, switch in one tap
  - Severity, meaning, causes and numbered fix steps for every code
  - Save codes, and search inside brands, model lines and codes
  - No account, no tracking, no runtime permissions

 10. TESTING TRACKS AND PRODUCTION
--------------------------------------------------------------------------------

  Recommended order:

  1. Internal testing (fastest, up to 100 testers)
     Release -> Testing -> Internal testing -> Create new release.
     Upload ac-ustad-1.0.1.aab.
     Add your own Google account as a tester, roll out, install from the
     opt-in link, and check:
       - app opens in airplane mode
       - all 4,418 codes are readable
       - English / Roman Urdu switches
       - Saved tab, swipe-to-remove and undo work
       - one banner ad appears when online
       - no crash on first launch

  2. Closed testing (required before production for new personal accounts)
     Release -> Testing -> Closed testing -> Create new release.
     Add at least 12 testers (their Google accounts) and keep the test running
     for 14 continuous days. Then apply for production access on the
     Publishing overview page.

  3. Production
     Release -> Production -> Create new release.
     Upload the same ac-ustad-1.0.1.aab (or promote the tested release).
     Add the R8 mapping file:
       App bundle explorer -> Downloads -> Upload deobfuscation file
       (or the "Deobfuscation file" field on the release) ->
       mapping-1.0.1.txt
     Review the pre-launch report, then roll out.

  Play review usually takes a few hours to a few days for a new app.

 12. UPDATES AFTER 1.0.1
--------------------------------------------------------------------------------

  1. Change the app code/data.
  2. Bump versionCode by at least 1 in android/app/build.gradle.kts
     (4 -> 5 -> 6 ...). Play rejects a versionCode it has already seen.
     Bump versionName too (for example 1.0.2).
  3. Update the staged file names in .github/workflows/build-release.yml
     (ac-ustad-1.0.1.aab -> ac-ustad-1.0.2.aab, same for .apk and mapping).
  4. Commit, push, run build-release, download the new artifact.
  5. Upload the new .aab to Production (or a testing track first).
  6. Upload the new mapping file with the release.

  Data-only updates that do not change the app still need a versionCode bump
  because the database is bundled in the APK/AAB.

 13. COMMON REJECTIONS AND FIXES
--------------------------------------------------------------------------------

  "App must target Android 16 (API 36) or higher"
    The AAB already targets 36. If this appears, you uploaded an old file.
    Re-download from the run in section 2 and check targetSdkVersion 36.

  "You need to use Play App Signing"
    Setup -> App signing -> enroll, then re-upload the same AAB.

  "Version code 3 has already been used"
    Bump versionCode to 5, rebuild, upload the new AAB.

  "Missing privacy policy"
    Paste the URL from section 5 in App content -> Privacy policy.

  "Data safety is incomplete"
    Complete every card in section 8, including the advertising ID card.

  "App contains ads but ads declaration is missing"
    App content -> Ads -> YES.

  "Invalid or missing deobfuscation file"
    Upload mapping-1.0.1.txt on the release, or ignore it (optional; only
    affects crash report readability).

  "App is not available in your country"
    Check Store settings -> Countries / regions includes the target country.

  "Pre-launch report shows a crash"
    Read the stack trace with mapping-1.0.1.txt, fix, bump versionCode,
    rebuild, re-upload.
